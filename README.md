# 


予文字以清净，还阅读以澄澈。

澄阅（Web Reader）是一个轻量级网页阅读工具：粘贴文章链接，自动提取正文，提供干净、专注的阅读体验。支持深色模式、阅读历史、Markdown 导出与浏览器书签一键跳转。

## 在线体验

> **在线地址：** `https://your-app-name.onrender.com`（部署后替换为实际地址）

## 书签安装

安装书签后，可在任意网页上一键将当前页面发送到澄阅阅读。

### 步骤一：打开澄阅首页

在浏览器中访问在线地址或本地 `http://localhost:3000`，滚动至页面底部的「书签安装」区域。

```
┌─────────────────────────────────────┐
│  澄阅                          🌙 ⬇ │
├─────────────────────────────────────┤
│                                     │
│   予文字以清净，                     │
│         还阅读以澄澈                 │
│   ────                              │
│   [ 粘贴文章链接到这里...        ]  │
│   [      开始阅读               ]  │
│                                     │
│   ┌─ 书签安装 ─────────────────┐   │
│   │ 将下方按钮拖拽至书签栏...   │   │
│   │  📖 澄阅 · 阅读此页  ←拖我  │   │
│   │  javascript:(function(){... │   │
│   └─────────────────────────────┘   │
└─────────────────────────────────────┘
```

### 步骤二：显示书签栏

若看不到书签栏，请先将其开启：

| 浏览器 | 操作 |
|--------|------|
| Chrome / Edge | 按 `Ctrl+Shift+B`（Mac：`⌘+Shift+B`） |
| Firefox | 右键顶部空白处 → 勾选「书签工具栏」 |
| Safari | 菜单栏 → 显示 → 显示收藏夹栏 |

### 步骤三：拖拽安装

用鼠标按住 **「📖 澄阅 · 阅读此页」** 按钮，拖到浏览器书签栏上方，松开鼠标即可完成安装。

```
  书签栏
  ┌──────────────────────────────────────────┐
  │ 📖 澄阅 · 阅读此页  │  其他书签...        │
  └──────────────────────────────────────────┘
         ↑
    拖拽到这里
```

### 步骤四：使用书签

在任意文章页面点击书签，澄阅会在新标签页打开并自动加载该页正文。

> **备选方式：** 点击书签代码区域（灰色背景），复制 `javascript:...` 代码，在书签管理器中新建书签，将 URL 粘贴进去即可。

## 本地运行

### 环境要求

- Node.js 18 或更高版本
- npm

### 安装与启动

```bash
# 克隆项目
git clone <your-repo-url>
cd web-reader

# 安装依赖
npm install

# 启动服务
npm start
```

启动后在浏览器访问 [http://localhost:3000](http://localhost:3000)。

### API 接口

```
GET /api/extract?url=<文章链接>
```

返回 JSON，包含 `title`、`content`（HTML）、`wordCount`、`markdown` 等字段。

## 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 运行时 | Node.js | 服务端运行环境 |
| Web 框架 | Express | 静态资源托管与 API 路由 |
| HTTP 客户端 | axios | 抓取目标网页 HTML |
| DOM 解析 | jsdom | 在服务端构建 DOM 环境 |
| 正文提取 | @mozilla/readability | 识别并提取文章正文（Firefox 阅读模式同款算法） |
| 格式转换 | turndown | 将 HTML 正文转换为 Markdown |
| 前端 | 原生 HTML / CSS / JavaScript | 阅读界面、主题切换、历史记录 |

部署配置见项目根目录 [`render.yaml`](./render.yaml)。

## 隐私说明

澄阅重视你的阅读隐私：

- **阅读历史、主题偏好** 均保存在浏览器 `localStorage` 中，不会上传到服务器。
- **服务器不持久化** 任何用户账号、阅读记录或个人数据；`/api/extract` 仅在请求时临时抓取并解析网页，响应后即结束。
- **导出功能** 在本地生成 Markdown 文件，数据不经过第三方。
- 清除浏览器站点数据即可删除全部本地记录。

如需完全离线使用历史与偏好，请勿在公共设备上使用，或定期点击底部「清空」按钮清除历史记录。
